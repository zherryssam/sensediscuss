# 오감이 사라진다면? — 우리 반 감각 중요도 순위

학생들이 살리고 싶은 감각과 이유를 적고, 서로의 이유를 읽은 뒤 1~5위 순위를 매겨 “우리 반 감각 중요도 순위”를 발표하는 실시간 수업용 웹앱입니다.

```
학생·교사 브라우저 ──(2초마다 확인)──▶ Google Apps Script 웹앱 ──▶ 구글 시트(백업·결과표)
        ▲ GitHub Pages(docs/)                (gas/Code.gs)
```

- **프런트**: `docs/` (정적 HTML/JS) → GitHub Pages로 호스팅
- **백엔드**: `gas/Code.gs` → Google Apps Script 웹앱 (서버 비용·관리 없음)
- **“실시간”의 의미**: Apps Script는 푸시(WebSocket)가 없어서 각 화면이 **약 2초마다** 변경을 확인합니다. 선택·공감·타이머가 2초 안팎으로 반영돼요. 내가 누른 동작은 바로 반영됩니다.

## 배포 방법 (처음 한 번, 약 10분)

### 1. 구글 시트 + Apps Script
1. [sheets.new](https://sheets.new)로 새 스프레드시트를 만들고 이름을 정해요(예: `오감 수업`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 열어요.
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 [`gas/Code.gs`](gas/Code.gs) 내용을 통째로 붙여넣어요.
4. 맨 위의 `TEACHER_PASSWORD = ''` 에 **교사 비밀번호**를 적어요. (비워 두면 주소를 아는 누구나 방을 열 수 있어요.)
5. (선택) 왼쪽 ⚙ **프로젝트 설정 → “appsscript.json 매니페스트 파일 표시”** 를 켜고 [`gas/appsscript.json`](gas/appsscript.json) 내용으로 바꿔요. (시간대 등. 생략해도 배포 화면에서 설정 가능)

### 2. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
2. **다음 사용자 인증으로 실행: 나** / **액세스 권한: 모든 사용자** ← 꼭 “모든 사용자”여야 GitHub Pages에서 호출돼요.
3. **배포** → 권한 승인(처음 한 번: “고급 → 안전하지 않음으로 이동” 후 허용) → **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
4. 확인: 그 URL 뒤에 `?a=ping` 을 붙여 열면 `{"ok":true,...}` 가 보여야 해요.

> `Code.gs`를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 로 갱신해야 반영돼요. (주소는 그대로)

### 3. 프런트 설정 + GitHub Pages
1. [`docs/config.js`](docs/config.js) 의 `APPS_SCRIPT_URL` 을 복사한 웹 앱 URL로 바꿔요.
2. GitHub에 저장소를 만들어 올려요.
   ```bash
   git init && git add . && git commit -m "오감 중요도 수업"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / 폴더 `/docs`** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 가 학생 주소, `…/teacher.html` 이 교사 주소예요.

## 수업 진행
교사가 `teacher.html`에서 비밀번호를 넣고 **새 수업 열기** → 4자리 방 코드와 학생 주소를 안내해요.

1. **사전 투표 + 이유** – 입장하자마자 살리고 싶은 감각 1개를 고르고 이유(150자)를 적어요. 단계가 넘어가기 전까지 수정 가능.
2. **이유 모아보기** – 감각별로 모인 이유를 읽고 👍 공감.
3. **순위 정하기** – ▲▼ 버튼으로 1~5위를 정해 제출 (발표 전까지 수정 가능).
4. **순위 발표** – n위 감각에 n점, **총점이 낮은 순서**로 순위를 매겨요. 동점이면 1위 득표가 많은 쪽, 그래도 같으면 공동 순위. 교사가 5위부터 한 칸씩 공개해요.

교사 도구: 제출 현황, 📌 이유 크게 보기, 익명/실명 토글, 이유 숨기기, ⏱ 타이머(1·3·5분), 📥 결과 CSV, 📊 **구글시트에 저장**(`result-방코드` 시트에 결과표 작성 — 발표 단계로 넘어가면 자동 저장됨).

## 한계와 팁
- **동시 접속**: 학생 40명 정도까지 권장해요. Apps Script는 동시 실행 30개 제한이 있어 폴링 간격(2초)을 둔 것이고, 화면이 가려진 탭은 자동으로 더 천천히 확인해요. 큰 학년 단위는 반별로 방을 나눠 주세요.
- **첫 응답이 느릴 수 있어요**: Apps Script 특성상 한동안 쓰지 않으면 첫 요청이 1~3초 걸려요. 수업 직전에 교사가 방을 열어 두면 좋아요.
- **데이터 보관**: 진행 중 상태는 캐시(최대 6시간)에 있고, 단계가 바뀔 때·30초마다 `snapshots` 시트에 백업돼 캐시가 비워져도 복구돼요(마지막 30초 이내의 입력은 유실될 수 있음). 학생 이름·이유가 시트에 남으니 수업 후 `snapshots` 시트를 지워 주세요.
- **비밀번호**: 교사 비밀번호는 방 개설에만 쓰여요. 방 코드를 아는 사람은 학생으로 입장할 수 있으니, 코드는 수업 중에만 공유하세요.
- 학생 이름은 8자, 이유는 150자까지, 방당 최대 100명입니다.

## 로컬에서 테스트
Apps Script 없이도 `gas/Code.gs`를 그대로 시뮬레이션하는 개발 서버가 있어요(Node.js 18+).
```bash
node dev-server.js
```
`http://localhost:3000/teacher.html` (교사) · `http://localhost:3000/` (학생). `localhost`에서는 `config.js`가 자동으로 개발 서버를 쓰므로 설정을 바꿀 필요가 없어요.
